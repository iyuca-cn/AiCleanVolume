# 清理建议页提示词编辑设计

## 背景

当前 AI 系统提示词位于设置页，用户在清理建议页执行 `AI 识别` 前，需要切换到设置页修改提示词，再回到清理建议页执行分析。这个路径不符合“按当前磁盘和当前任务快速调整 AI 判断口径”的使用场景。

## 方案

在清理建议页工具栏新增 `提示词` 按钮，点击后打开 AntdUI 模态窗口。窗口内提供提示词预设下拉和多行系统提示词编辑框，并使用当前清理建议页选择的盘符生成盘符范围提示。用户点击保存后，将内容写回现有 `settings.Ai.SystemPrompt`，同步提示词预设状态，并持久化到 `appsettings.json`。

设置页移除原提示词预设下拉和系统提示词输入框，不再承担提示词编辑职责。设置页继续保留 AI 接入、配置方案、测试、建议条数、沙盒和删除策略相关设置。

## 架构

继续复用现有 `AiPromptPreset`、`FindAiPromptPreset`、`NormalizePromptForComparison` 和 `BuildDriveScopedPrompt` 逻辑，不新增并行配置模型。提示词仍是 `AiSettings.SystemPrompt` 的单一来源，AI 请求链路无需修改。

提示词弹窗作为 `MainWindow` 的 UI 行为，使用 AntdUI 控件构建内容，不使用 C# 原生 UI，也不修改第三方 AntdUI 源码。

## 交互

1. 清理建议页工具栏显示 `提示词` 按钮，位于 `AI 识别` 附近。
2. 点击按钮打开模态窗口。
3. 模态窗口显示：
   - 当前提示词预设；
   - 可编辑的系统提示词；
   - 保存和取消按钮。
4. 选择预设时，将提示词更新为该预设在当前盘符下的完整提示词。
5. 手动修改提示词后，预设自动切到 `自定义` 或匹配回对应预设。
6. 保存后立即持久化，下一次 `AI 识别` 使用新提示词。

## 验证

- 构建 `AiCleanVolume.sln -c Debug`。
- 确认设置页不再出现提示词编辑区。
- 确认清理建议页 `提示词` 按钮可打开弹窗、选择预设、保存提示词。
- 确认 AI 请求仍读取 `settings.Ai.SystemPrompt`。
