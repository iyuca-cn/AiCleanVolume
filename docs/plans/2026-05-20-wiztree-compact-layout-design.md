# WizTree 紧凑布局设计

## 背景

当前主界面右侧内容区包含全局页面标题栏，扫描页又有一块较高的扫描卡片。该结构留白较多，表格区进入首屏的位置偏低，不符合磁盘空间分析工具“先看数据、快速操作”的使用习惯。

用户期望右侧内容区学习 WizTree 的紧凑工具布局，同时左侧导航学习 TroveKit 的展开/折叠形态。项目仍必须使用 AntdUI 控件，不修改第三方库代码，并保持现有微内核服务组织方式。

## 目标

1. 保留左侧“扫描 / 清理建议 / 日志管理 / 设置”导航。
2. 移除每个页面右侧顶部的大标题与描述栏。
3. 扫描页右侧改为 WizTree 式工具条和数据区，减少卡片化留白。
4. 清理建议、日志、设置页面同样去掉大抬头，保留必要操作区。
5. 左侧导航支持展开和折叠：展开显示图标与文字，折叠仅显示图标。
6. 不加入 WizTree 的捐赠、更新提示等无关区域。

## 方案

### 主框架

- 保留当前 AntdUI `Window`、左侧导航和页面切换机制。
- 移除右侧 `titleBar` 对内容区的占位，不再在每页显示“扫描界面 / 清理建议 / 日志管理 / 设置界面”的标题说明。
- 保留窗口最顶部的应用栏，用于显示应用名和窗口控制按钮；应用栏高度保持紧凑。
- 右侧 `pageHost` 缩小外边距，页面内容从顶部工具条直接开始。

### 左侧导航

- 展开态继续显示品牌、导航图标和文字，风格参考 TroveKit。
- 折叠态宽度约 72 像素，只显示图标，设置入口仍固定在底部。
- 折叠按钮放在侧栏右缘中上部，使用圆形 AntdUI 按钮。
- 侧栏宽度变化复用现有宽度保存逻辑，但折叠态单独保存状态，避免用户手动调整宽度后被覆盖。
- 导航项选中态使用浅蓝底和主色图标/文字；折叠态保持同样的选中背景。

### 扫描页

- 顶部扫描卡片改为浅色工具条，高度控制在约 104 到 124 像素。
- 工具条第一行放：盘符选择、扫描按钮、路径输入、容量摘要。
- 工具条第二行放：最小值、层级限制、排序、扫描状态和进度。
- 工具条下方直接是空间树表格，不再使用大圆角卡片和明显阴影。
- 表格边框、表头和滚动条保持 AntdUI 表格风格，显示密度接近 WizTree。

### 清理建议页

- 去掉页内“清理建议”标题和描述。
- 顶部改为一行或两行紧凑工具条：盘符、最小值、数量限制、权限开关、全选/全不选/反选。
- 主要操作按钮仍放在页面可见操作区或窗口应用栏右侧，但不依赖已移除的大标题栏。
- 下方直接显示建议表格。

### 日志页

- 去掉大标题说明。
- 日志区域从顶部开始显示，必要时保留轻量操作条。
- 日志输入框继续使用 AntdUI 控件，并保持只读日志查看行为。

### 设置页

- 去掉右侧全局标题栏后，设置页内部仍保留分组结构。
- 不强行做成表格工具页，避免降低配置可读性。
- 缩小页面顶部空白和分组间距，让首屏看到更多配置。

## 数据与状态

- 页面切换仍使用现有 `SetActivePage`。
- 原本挂在 `titleBar` 上的操作按钮需要迁移到各页面的工具条或固定操作区。
- 扫描状态仍由 `UpdateScanProgressState` 驱动，只调整控件所在位置。
- 磁盘摘要仍复用现有 `UpdateDriveSummary` 相关数据，不新增扫描服务路径。
- 侧栏折叠状态写入应用设置；若设置模型暂不扩展，则先仅在运行期保存，不引入回退配置。

## 错误处理

- 控件迁移不改变扫描、AI 建议、删除和日志服务逻辑。
- 忙碌态仍由 `SetBusy` 统一控制按钮启用和加载状态。
- 如果页面未创建完成，相关 UI 更新方法保持空值保护。
- 不引入“临时兜底”布局或备用 UI 架构。

## 验证

1. Debug 编译通过。
2. 启动后右侧不再出现页面大标题栏。
3. 扫描页首屏展示紧凑工具条和空间树表格。
4. 清理建议、日志、设置页不再出现顶部大抬头。
5. 左侧导航可展开/折叠，折叠态只显示图标，底部设置入口可用。
6. 扫描、AI 识别、常规清理、超级清理、删除勾选和保存配置按钮仍能在对应页面触发。
7. `git status --short` 确认未修改第三方库。
